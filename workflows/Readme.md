# Magento 2 CI/CD Pipeline - DevOps

Automated deployment for Magento 2 store to AWS EC2.

### Features
- Auto deploy on git push using GitHub Actions
- Magento upgrade, compile, deploy commands automated
- Zero downtime deployment script

### Tech Stack
AWS EC2, GitHub Actions, Magento 2, Nginx, PHP, Bash

### Setup Secrets in GitHub
EC2_HOST = Your EC2 IP
EC2_SSH_KEY = Your .pem key content
